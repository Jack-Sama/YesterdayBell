# 昨天的放学铃

毕业典礼前一天，朝仓悠和夏澄回到旧教室做最后一次值日。她带着相机，他翻出一本还能听见过去的值日簿。

**放学留影版 0.2.0**是一部用 Ren’Py 制作的简体中文短篇视觉小说，共五章、六处选择界面、两个结局。

## 试玩

从 [v0.2.0 版本页](https://github.com/Jack-Sama/YesterdayBell/releases/tag/v0.2.0) 下载 Windows 压缩包，解压后双击 `YesterdayBell.exe`。

要编辑游戏，在 Ren’Py 8.5.3 启动器中将项目目录设为仓库的上一级目录，选择本项目后启动。剧本在 `game/script.rpy`，界面在 `game/bell_ui.rpy`。
